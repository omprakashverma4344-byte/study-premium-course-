# Included features

Student: home, courses, search, course details, UPI/QR purchase form, UTR submission, account, approved course library, protected content access.

Admin: secure cookie login, dashboard stats, payment approval/rejection, course create/delete, content upload, B2 integration.

Security: server-side entitlement check, JWT sessions, password comparison, unique UTR, private B2 signed URLs, no client-side paid flag.

Optional integrations: Telegram Bot API.
